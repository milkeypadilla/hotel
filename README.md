## How a reservation works
1. The guest picks check-in, check-out and number of guests on **Find a room**.
2. Only rooms that fit the guests and have no overlapping pending or confirmed reservation are shown.
3. The guest confirms the booking. It starts as **Pending** and the total is nights x price per night.
4. The admin **confirms** it, then **checks the guest out** after the stay (Completed). Either side can cancel.
